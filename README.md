# Mini_Python_Banking_Project

Banking KPI Dashboard Analysis

1. Introduction

This project demonstrates a complete data analysis pipeline for banking data using Python in Jupyter Notebook.

As a data analyst, this showcases end-to-end skills from data generation to PDF reporting, perfect for portfolio demonstration.
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

2. Objective: 

Analyze customer banking data to uncover actionable KPIs like account performance,

customer segmentation, 
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

 3. Business Benefits

* Identify profitable segments - Average balance by account type/branch

* Track growth trends - Quarterly balance performance

* Risk assessment - Loan default patterns by age/demographics

* Customer insights - Age group and account distribution analysis

* Stakeholder reporting - Professional PDF export with 5 KPI charts

4. Technology Used

* Pandas, Numpy

* matplotlib, Seaborn

* matplotlin.backend PDF Exports
